# Группировка слов по длине

Реализуйте `group_by_length(words)`. Ключ результата — длина слова, значение —
список слов такой длины в исходном порядке. Пустой вход даёт пустой словарь.

Задача показывает, что значениями словаря могут быть изменяемые коллекции.
Попробуйте сначала проверять наличие ключа явно, а затем познакомьтесь с
`dict.setdefault`.

Запуск: `pytest 03_dictionaries/02_group_by_length`.
