# Счётчик слов

Реализуйте `word_counts(words)`: посчитайте слова без учёта регистра и верните
словарь `{слово: количество}`. Например, `"Cat"` и `"cat"` относятся к одному
ключу `"cat"`. Для пустого списка верните пустой словарь.

Для первого решения достаточно цикла, проверки ключа через `in` и обращения к
значению по ключу. После этого познакомьтесь с методом `dict.get`.

Запуск: `pytest 00_basics/03_dictionaries`.

## Полезные материалы

- [Словари](https://docs.python.org/3/tutorial/datastructures.html#dictionaries) — ключи, значения и проверка наличия ключа.
- [`dict.get`](https://docs.python.org/3/library/stdtypes.html#dict.get) — значение по умолчанию для отсутствующего ключа.
