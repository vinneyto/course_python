# Декоратор счётчика вызовов

Реализуйте декоратор `count_calls`, применимый без скобок. Обёрнутая функция
принимает те же позиционные и именованные аргументы, возвращает исходный
результат и сохраняет метаданные через `functools.wraps`. После каждого вызова,
включая завершившийся исключением, атрибут `calls` обёртки увеличивается на один.
У каждой декорированной функции должен быть независимый счётчик.

## Полезные материалы

- [`functools.wraps`](https://docs.python.org/3/library/functools.html#functools.wraps) — перенос метаданных функции.
- [`finally`](https://docs.python.org/3/reference/compound_stmts.html#finally) — действие независимо от результата вызова.
- [`ParamSpec`](https://docs.python.org/3/library/typing.html#typing.ParamSpec) — сохранение типов параметров декорируемой функции.
