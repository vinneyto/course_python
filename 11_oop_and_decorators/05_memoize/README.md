# Декоратор мемоизации

Реализуйте параметризованный декоратор `memoize(maxsize=None)`. Он кеширует
результаты функции по комбинации позиционных и именованных аргументов. Порядок
именованных аргументов не должен создавать разные записи. При `maxsize` кеш
работает как LRU: успешное обращение освежает запись, а переполнение удаляет
давно не использованную. `None` означает неограниченный кеш, положительное целое
— предел; остальные значения дают `ValueError` при создании декоратора.

Сохраните метаданные функции. Добавьте обёртке метод `cache_clear()`, который
полностью очищает кеш. Нехешируемые аргументы могут приводить к `TypeError` и
кешировать исключения не требуется.

## Полезные материалы

- [`functools.wraps`](https://docs.python.org/3/library/functools.html#functools.wraps) — корректная функция-обёртка.
- [`OrderedDict`](https://docs.python.org/3/library/collections.html#collections.OrderedDict) — перестановка и удаление LRU-записей.
- [`functools.lru_cache`](https://docs.python.org/3/library/functools.html#functools.lru_cache) — промышленный аналог для сравнения после решения.
