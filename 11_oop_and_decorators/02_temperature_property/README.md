# Управляемая температура

Реализуйте класс `Temperature`. Конструктор принимает градусы Цельсия через
свойство `celsius`. Значение ниже абсолютного нуля (`-273.15`) отклоняется с
`ValueError`. Свойство `fahrenheit` пересчитывает температуру в обе стороны и
тоже имеет setter. Свойство `kelvin` доступно только для чтения.

Не храните три копии значения: единственным источником истины должен быть
приватный атрибут с температурой в градусах Цельсия.

## Полезные материалы

- [`property`](https://docs.python.org/3/library/functions.html#property) — getter и setter управляемого атрибута.
- [Протокол дескрипторов](https://docs.python.org/3/howto/descriptor.html#properties) — как `property` устроен внутри.
