# Последние строки большого файла

Реализуйте `tail(path, count, encoding="utf-8")`: верните последние `count`
строк без переводов строки. Нельзя читать файл целиком: двигайтесь блоками с
конца в бинарном режиме, затем декодируйте результат. Учтите пустой файл,
последний `\n` и многобайтный UTF-8. `count < 0` — `ValueError`.

## Полезные материалы

- [`open()`](https://docs.python.org/3/library/functions.html#open) — различия текстового и бинарного режимов и параметры кодировки.
- [`io.IOBase.seek`](https://docs.python.org/3/library/io.html#io.IOBase.seek) — перемещение по файлу относительно начала, текущей позиции или конца.
- [Стандартные кодировки](https://docs.python.org/3/library/codecs.html#standard-encodings) — почему символ UTF-8 может занимать несколько байт и декодировать нужно только собранный диапазон.
