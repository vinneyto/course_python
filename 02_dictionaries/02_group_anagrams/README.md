# Группировка анаграмм

Реализуйте `group_anagrams(words)`: объедините слова, состоящие из одинаковых
букв, в группы. Регистр при сравнении не учитывается, но в результате слова
должны остаться в исходном виде. Группы и слова внутри них сохраняют порядок
первого появления во входной последовательности.

Пример: `["кот", "ток", "сон", "Кто"] → [["кот", "ток", "Кто"], ["сон"]]`.

Запуск: `pytest 02_dictionaries/02_group_anagrams`.

## Полезные материалы

- [`dict.setdefault`](https://docs.python.org/3/library/stdtypes.html#dict.setdefault) — создание группы при первом появлении ключа.
- [`sorted`](https://docs.python.org/3/library/functions.html#sorted) — построение канонического ключа из букв слова.
