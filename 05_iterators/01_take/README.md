# Первые элементы итератора

Реализуйте `take(iterable, count)`, возвращающую список из не более чем `count`
первых элементов. При `count <= 0` верните пустой список. Вход может быть
генератором, поэтому не преобразовывайте его целиком в список.

Это первая встреча с протоколом итерации: получите итератор через `iter()`,
запрашивайте значения через `next()` и обработайте `StopIteration`.

Запуск: `pytest 05_iterators/01_take`.

## Полезные материалы

- [`iter` и `next`](https://docs.python.org/3/library/functions.html#iter) — ручное управление итерацией.
- [Типы итераторов](https://docs.python.org/3/library/stdtypes.html#iterator-types) — почему окончание обозначается `StopIteration`.
