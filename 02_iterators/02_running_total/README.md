# Накопительная сумма

Реализуйте генератор `running_total(numbers)`. После каждого входного числа он
должен выдавать сумму всех увиденных чисел: для `[2, -1, 4]` получится
`2, 1, 5`. Пустой вход ничего не выдаёт.

Не создавайте список результатов: храните только текущую сумму и используйте
`yield`. Так задача связывает знакомый цикл с ленивыми генераторами.

Запуск: `pytest 02_iterators/02_running_total`.
