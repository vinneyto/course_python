# Фильтрация списка

Реализуйте `positive_squares(numbers)`. Верните новый список квадратов только
положительных чисел в исходном порядке. Не изменяйте входной список.

Сначала напишите обычный цикл с `append`, а затем, если он понятен, попробуйте
переписать его как list comprehension.

Запуск: `pytest 02_lists/01_positive_squares`.
