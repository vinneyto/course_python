# Транспонирование таблицы

Реализуйте `transpose(matrix)` для непустой прямоугольной матрицы: её строки
должны стать колонками. Для пустой матрицы верните пустой список. Можно считать,
что все строки имеют одинаковую длину.

Сначала решите задачу двумя вложенными циклами. Это упражнение закрепляет
индексы и создание вложенных списков.

Запуск: `pytest 02_lists/03_transpose`.
