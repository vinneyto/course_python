# Удаление повторов из списка

Реализуйте `remove_duplicates(items)`: верните новый список, оставив только
первое появление каждого числа и сохранив исходный порядок. Входной список не
изменяйте.

Одного преобразования в `set` недостаточно, потому что порядок результата
должен быть предсказуемым. Используйте множество для проверки уже встреченных
значений и список для результата.

Запуск: `pytest 02_lists/02_remove_duplicates`.
