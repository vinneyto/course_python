# Статистика посетителей

Реализуйте `visitor_stats(yesterday, today)`. Верните кортеж из двух множеств:
все уникальные посетители за оба дня и посетители, которые появились только
сегодня. Повторные имена в списках не влияют на результат.

Задача тренирует объединение `|` и разность `-` множеств.

Запуск: `pytest 04_sets/02_unique_visitors`.
