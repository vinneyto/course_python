# Подсчёт гласных

Реализуйте `count_vowels(text)`, которая считает русские и английские гласные
без учёта регистра. Считайте гласными `aeiouy` и `аеёиоуыэюя`. Остальные буквы,
цифры, пробелы и знаки препинания пропускайте.

Начните с переменной-счётчика и цикла по строке. Для проверки символа удобно
использовать оператор `in`.

Запуск: `pytest 01_strings/02_count_vowels`.
