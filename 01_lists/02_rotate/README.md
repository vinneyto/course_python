# Циклический сдвиг списка

Реализуйте `rotate(items, steps)`, которая возвращает **новый** список,
циклически сдвинутый вправо на `steps` позиций. Отрицательное значение означает
сдвиг влево. Исходный список изменять нельзя. Для пустого списка верните `[]`.

Примеры: `rotate([1, 2, 3, 4], 1) → [4, 1, 2, 3]`,
`rotate([1, 2, 3], -1) → [2, 3, 1]`.

Запуск: `pytest 01_lists/02_rotate`.

## Полезные материалы

- [Срезы последовательностей](https://docs.python.org/3/library/stdtypes.html#common-sequence-operations) — создание частей списка без его изменения.
- [Оператор `%`](https://docs.python.org/3/reference/expressions.html#binary-arithmetic-operations) — нормализация большого или отрицательного сдвига.
