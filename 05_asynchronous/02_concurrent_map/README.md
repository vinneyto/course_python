# Параллельный запуск корутин

Реализуйте `concurrent_map(func, values)`. Вызовите асинхронную `func` для всех
значений конкурентно и верните результаты в порядке входных значений. Для
пустого входа верните пустой список.

Используйте `asyncio.gather`. Не пишите `await func(value)` внутри обычного
цикла: такой вариант выполняет операции последовательно. Эта ступень добавляет
конкурентность после простой одиночной корутины, но ещё не требует ручного
управления задачами.

Запуск: `pytest 05_asynchronous/02_concurrent_map`.

## Полезные материалы

- [`asyncio.gather`](https://docs.python.org/3/library/asyncio-task.html#asyncio.gather) — конкурентное ожидание и порядок результатов.
- [Конкурентный запуск задач](https://docs.python.org/3/library/asyncio-task.html#creating-tasks) — отличие корутин от запланированных задач.
