# Fan-in очередей

Реализуйте `fan_in(sources)`: объедините несколько `queue.Queue` в один
итератор. Каждый producer завершает поток уникальным объектом `DONE`. Порядок
между источниками не определён, внутри каждого сохраняется. Нельзя ждать
первую очередь до конца: обслуживайте источники конкурентно и корректно
завершите вспомогательные потоки.
