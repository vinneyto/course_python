# Валидирующий дескриптор

Реализуйте generic-дескриптор `Validated`. Он принимает validator и хранит
значение отдельно в каждом экземпляре-владельце. До присваивания чтение бросает
`AttributeError`. Имя поля определяется через `__set_name__`; доступ через класс
возвращает сам дескриптор. Validator может нормализовать значение или бросить
исключение.
