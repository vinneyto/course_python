# Извлечение хештегов

Реализуйте `extract_hashtags(text)`: найдите в тексте слова, начинающиеся с
`#`, и верните их без решётки в нижнем регистре. Хештег состоит только из букв,
цифр и символа `_`; одна решётка хештегом не считается. Повторения сохраняйте,
а знаки препинания после хештега не включайте в результат.

Примеры: `"Люблю #Python и #Тесты!" → ["python", "тесты"]`,
`"#one,#TWO и просто #" → ["one", "two"]`.

Запуск: `pytest 00_strings/02_extract_hashtags`.

## Полезные материалы

- [`str.isalnum`](https://docs.python.org/3/library/stdtypes.html#str.isalnum) — проверка букв и цифр, включая Unicode.
- [`str.lower`](https://docs.python.org/3/library/stdtypes.html#str.lower) — приведение строки к нижнему регистру.
