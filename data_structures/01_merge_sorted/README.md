# Слияние отсортированных потоков

Реализуйте `merge_sorted(iterables)`, лениво сливающую любое число
отсортированных по возрастанию iterable. Входы могут быть бесконечными;
материализовывать их нельзя. Сохраняйте дубликаты. Пустой список допустим.

**Вопросы:** какова сложность выдачи одного элемента? Почему heap лучше поиска
минимума по всем потокам?

Запуск: `pytest collections/01_merge_sorted`.
