# Последние строки большого файла

Реализуйте `tail(path, count, encoding="utf-8")`: верните последние `count`
строк без переводов строки. Нельзя читать файл целиком: двигайтесь блоками с
конца в бинарном режиме, затем декодируйте результат. Учтите пустой файл,
последний `\n` и многобайтный UTF-8. `count < 0` — `ValueError`.
