# Общие уникальные элементы

Реализуйте `common_unique(left, right)`. Верните уникальные строки, которые
есть в обоих списках, отсортировав результат по возрастанию. Если общих строк
нет, верните пустой список.

Задача знакомит с преобразованием списка во множество и операцией пересечения.
Обратите внимание: множество не обещает порядок, поэтому результат нужно явно
отсортировать.

Запуск: `pytest 03_sets/01_common_unique`.
